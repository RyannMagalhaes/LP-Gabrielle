# Brand Assets

Os arquivos desta pasta são assets oficiais da identidade visual de Gabrielle Favere.

## Regras

- Não alterar a geometria dos logos/símbolos.
- Não sobrescrever os arquivos originais.
- Caso seja necessária adaptação de cor, criar uma cópia em `/derived`.
- Não utilizar filtros CSS agressivos para recoloração de PNG.
- Preferir a versão com melhor contraste para cada background.
## Prioridade de uso

1. Preferir `Logo_RGB.svg` para aplicações principais da marca.
2. Usar PNGs apenas quando forem variações específicas necessárias.
3. Não rasterizar o SVG desnecessariamente.
4. Se o SVG permitir recoloração por `fill`/`stroke`, criar uma cópia derivada e preservar o original.
5. Nunca alterar a geometria, proporções ou paths da marca.
